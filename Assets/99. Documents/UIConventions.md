# UI 작업 규칙 (범용)

프로젝트를 가리지 않고 적용되는 UGUI 작업 규칙이다. 특정 폰트·색·수치 같은 이 프로젝트 고유 규격은
`UITextStyleGuide.md`에 있고, 이 문서는 그 바깥의 일반 규칙만 담는다.
괄호 안 값은 Project-CSP의 실제 설정 예시이며, 다른 프로젝트에서는 그 자리에 자기 값을 넣는다.

---

## 1. 네이밍 — 접두사는 컴포넌트 종류, 뒤는 역할

`Btn_` `Img_` `Tmp_` `Slider_` `Toggle_` `Panel_` `Group_` + 역할명
(`Btn_TabAudio`, `Tmp_ResolutionValue`, `Img_RowHighlight`)

- `Group_`은 여러 요소를 묶어 하나의 단위로 쓰는 것에 붙인다. 화면 루트, 반복 슬롯 등.
  그래픽 컴포넌트가 없어도 붙는다.
- 순수 배치용 빈 오브젝트는 접두사 없이 역할명을 쓴다 (`ContentRoot`, `TabRoot`, `Viewport`).
- 프리팹 폴더도 같은 층위로 나눈다.
  `General`(원자 공용) / `UIContent`(반복 슬롯·행) / `UIView`(화면 단위) / `Setting`(캔버스 루트)
- 스크립트 클래스명은 프리팹명과 맞춘다 (`Group_RelicSlot` ↔ `RelicSlot.cs`).

## 2. 공용 프리팹을 거친다 — 특히 텍스트

- 폰트별 `Tmp_` 기본 프리팹을 만들어두고 **텍스트는 항상 그 프리팹 인스턴스로 생성한다.**
  TMP Settings의 Default Font Asset이 영문 폰트라 GameObject 메뉴로 새로 만들면 폰트 지정을 매번
  잊게 된다. 프리팹 경유가 유일한 안전장치다.
- 다만 1순위는 **같은 화면의 형제 요소 복제**다. General 프리팹은 기본값만 들고 있어
  역할 정보(사이즈·색·머티리얼)가 없다.
- 딤드, 슬라이더, 토글, 인디케이터도 종류당 하나씩만 두고 그것을 쓴다.

## 3. 캔버스 기준을 하나로 통일

- Screen Space + Scale With Screen Size + **Reference Resolution 한 값으로 고정** (1920×1080),
  프로젝트 내 모든 캔버스가 같은 값을 쓴다.
- 이래야 **TMP Font Size 값 == 기준 해상도의 픽셀 크기**가 되어 사이즈 규격표가 성립한다.
  캔버스마다 기준이 다르면 "36px 버튼" 같은 규격 자체가 의미를 잃는다.
- World Space 캔버스(유닛 머리 위 등)는 스케일 체계가 달라 규격 적용 대상에서 제외하고,
  그 사실을 문서에 명시한다.

## 4. 이미지 — PPU 정합과 SetNativeSize

- **UI 스프라이트 임포트 PPU를 한 값으로 고정**하고, Canvas의 `Reference Pixels Per Unit`이
  그 **정수배**가 되게 잡는다 (스프라이트 24 / 캔버스 96 → 정확히 4배).
  정수배가 아니면 픽셀아트가 뭉갠다.
- **Image는 예외 없이 SetNativeSize.** 런타임에 스프라이트를 갈아끼우는 슬롯(아이콘, 초상화)은
  세팅 코드에서 매번 `SetNativeSize()`를 호출한다.
- RectTransform **Scale은 항상 1**. 크기 조정은 원본 스프라이트를 고치거나 정수배로 한다.
  `0.87` 같은 스케일은 규격을 깨고 나중에 추적이 안 된다.
- 픽셀아트 텍스처는 Filter Mode `Point`, Compression `None`, Mipmap off.
- 9-slice는 스케일 대신 `pixelsPerUnitMultiplier`로 테두리 두께를 조절한다.
  기본값 1로 두고 필요한 것만 예외로 둔다.

## 5. Raycast Target은 기본 OFF

- 모든 Graphic의 `Raycast Target`은 **끄고 시작**한다. 켜는 것은 실제로 클릭을 받는 것뿐이다.
  버튼의 타겟 그래픽, 딤드, 입력 차단막.
- **텍스트는 항상 off.** 버튼 위 라벨이 클릭을 먹는 것이 가장 흔한 버그다.
- 코드로 생성하는 이펙트·오버레이 이미지는 **생성 직후 `raycastTarget = false`** 를 세트로 붙인다.
- 입력 차단은 개별 오브젝트를 끄지 말고 루트 `CanvasGroup`의 `blocksRaycasts`/`interactable`
  한 곳에서 처리한다.

## 6. 텍스트 규격

- **사이즈 스케일을 5~7단계로 고정**하고 표에 없는 값을 쓰지 않는다.
  한 화면에서 동시에 쓰는 단계는 **최대 4개**.
- **픽셀 폰트는 디자인 그리드의 배수만 쓴다.** 폰트의 em 크기를 확인해서 글자 전진 폭이
  정수 픽셀에 떨어지는 값만 허용한다 (12px 그리드 → 24/36/48, 20px 그리드 → 20/40).
- 하한은 기준 해상도의 접근성 하한을 따른다 (1080p면 18~20).
  **정보가 안 들어가면 폰트를 줄이지 말고 화면에 넣은 정보를 줄인다.**
- **Auto Sizing 기본 금지.** 넘치면 레이아웃을 고친다. 긴 서사 지면 같은 예외만 명시적으로 허용한다.
- Character Spacing 0. 여러 줄은 Line Spacing을 주고, 한 줄짜리 라벨은 0.
- **줄바꿈 후처리(어절 단위 유지 등)는 뷰의 텍스트 세팅 지점 한 곳에서** 통과시킨다.
  데이터에 `\n`을 박지 않는다.
- 색은 **토큰 10개 내외로 제한**하고 배경 계열별로 나눠 관리한다.
  본문 4.5:1 / 큰 텍스트 3:1 대비를 확인하고, 색만으로 정보를 전달하지 않는다.
- 폰트 머티리얼 프리셋은 `<폰트>_<용도>` 이름을 쓰고 문서에 한 줄 등록한다.
  화면 하나 때문에 프리셋을 늘리지 않는다.

## 7. 계층 구조

- **화면 하나 = 프리팹 하나 = View 클래스 하나.** 루트는 비활성 상태로 저장하고 `Show()`로 켠다.
  씬 로드 시 프레임 0 잔상을 막는다.
- 캔버스 컨테이너를 **HUD / Popup / Tooltip 3층**으로 나누고,
  팝업 스택과 입력 차단은 Popup 층만 참여시킨다.
- 반복 항목은 슬롯 프리팹 + 부모가 생성·바인딩하는 구조로 만든다.
  씬 안 템플릿 오브젝트는 비활성 원본으로 유지하고 첫 항목으로 쓰지 않는다.
- 참조는 전부 `[SerializeField]` 인스펙터 연결. 런타임 `Find`/탐색 금지.
- 인스펙터 필드 설명은 주석이 아니라 `[Tooltip]`으로 단다.

## 8. 셋업은 에디터 툴로

프리팹·씬 YAML을 직접 수정하는 대신 `MenuItem` 셋업 툴을 만든다. 조건은 세 가지다.

- **멱등** — 여러 번 실행해도 같은 결과
- 기존 값 존중 — 이미 채워진 참조를 덮어쓰지 않는다
- `Undo` 등록

손으로 만든 UI는 재현이 안 되고 리뷰도 안 된다.
